هدف تمرین و ساختار کلی

قرار است کتابخانه‌ای بسازید که بتواند سه نوع شیء Integer، Complex و Matrix را بسازد و عملیات جمع، ضرب و تفریق را روی آن‌ها انجام دهد. هدف فقط رسیدن به جواب عددی نیست؛ طراحی رابطه بین کلاس‌ها و نحوه استفاده از چندریختی نیز ارزیابی می‌شود.

AlgebraicElement(ABC)قرارداد مشترک عملیات
Integer
Complex
Matrix

نکته طراحی: در این تمرین هر سه کلاس می‌توانند جمع، ضرب و قرینه داشته باشند؛ بنابراین ارث‌بری از کلاس انتزاعی AlgebraicElement معنادار است. با این حال، Matrix «نوعی عدد صحیح یا مختلط» نیست و نباید از Integer یا Complex ارث ببرد.

قرارداد عمومی و قواعد مشترک

  • فایل‌های اجباری: algebra.py (شامل هر چهار کلاس) و test_algebra.py (تست‌های خودتان). می‌توانید فایل‌های کمکی بیشتری داشته باشید.
  • تمام متدهای معرفی‌شده در این صورت سؤال باید دقیقاً با نام و امضای خواسته‌شده پیاده‌سازی شوند. پارامتر self یا cls نیز مطابق نوع متد رعایت شود.
  • فیلدهای داخلی را با __ نگهداری کنید و ویژگی‌های عمومی اعلام‌شده را با @property فقط‌خواندنی ارائه دهید. نبودن Setter به‌تنهایی نباید موجب افشای لیست قابل‌تغییر داخلی شود.
  • برای اعداد صحیح پایتونی درون محاسبات مجازید از int استفاده کنید، اما خروجی عملیات عددی و اعضای ماتریس باید شیء Integer یا Complex باشد، نه int خام.
  • برای ورودی با نوع نامعتبر، TypeError و برای مقدار یا ابعاد نامعتبر، ValueError ایجاد کنید؛ استثناهای اختصاصی هر متد در پایین مشخص شده‌اند.
  • تابع multiply(a, b) مستقل از کلاس‌ها تعریف می‌شود و باید از Duck Typing استفاده کند.
بخش ۱

کلاس انتزاعی، وراثت و انواع عددی

۱ـ۱. کلاس AlgebraicElement

با استفاده از ABC و @abstractmethod این کلاس را پیاده کنید. ساخت مستقیم نمونه از آن مجاز نیست.

عضونوعرفتار
__add__(self, other)abstractجمع دو شیء
__mul__(self, other)abstractضرب دو شیء
__neg__(self)abstractساخت قرینه جمعی
__sub__(self, other)concreteفقط در کلاس پایه پیاده شود: self + (-other)

زیرکلاس‌ها نباید __sub__ را بازنویسی کنند؛ این بخش برای سنجش استفاده مجدد از کد به کمک وراثت است.

۱ـ۲. کلاس Integer(AlgebraicElement)

عضورفتار
__init__(self, value: int)فقط int واقعی قبول شود؛ bool مجاز نیست.
valueProperty فقط‌خواندنی از نوع int
from_string(cls, text: str)@classmethod؛ نمونه‌سازی از رشته‌هایی مثل "-12" یا "+7"
__add__، __mul__، __neg__پیاده‌سازی قرارداد کلاس پایه
__eq__(self, other)بررسی برابری عددی با Integer یا Complex

۱ـ۳. کلاس Complex(AlgebraicElement)

عضورفتار
__init__(self, real: int, imag: int)هر دو مؤلفه باید int واقعی باشند؛ bool مجاز نیست.
real، imagPropertyهای فقط‌خواندنی
from_string(cls, text: str)@classmethod؛ نمونه‌سازی از "5+2i" یا "-3-4i"
__add__، __mul__، __neg__پیاده‌سازی قرارداد کلاس پایه
__eq__(self, other)بررسی برابری عددی با Integer یا Complex

فرمت رشته مختلط دقیقاً a+bi یا a-bi است که در آن a و b اعداد صحیح دارای علامت اختیاری‌اند؛ مثلاً "0-2i" معتبر و "2i" در این تمرین نامعتبر است.

قوانین عملگرها در بخش ۱

  • Integer + Integer و Integer * Integer باید Integer جدید برگردانند.
  • در عملیات ترکیبی Integer و Complex، خروجی باید Complex باشد، حتی اگر بخش موهومی صفر باشد.
  • برای Complex(a,b) * Complex(c,d) از رابطه (ac − bd) + (ad + bc)i استفاده کنید.
  • Integer(3) == Complex(3,0) باید True باشد.
  • عملگرهای + و * روی دو عدد و نیز __neg__ شیء جدید ایجاد کنند و عملوندها را تغییر ندهند.
خروجی مورد انتظار بخش ۱: کلاس انتزاعی و دو زیرکلاس عددی، دو متد کلاسی تبدیل رشته، و تست‌های عملیات عددی و وراثت.
بخش ۲

کلاس ماتریس و متدهای ایستا / کلاسی

Matrix نیز از AlgebraicElement ارث‌بری می‌کند. خانه‌های آن فقط از نوع Integer یا Complex هستند و می‌توانند ترکیبی باشند.

۲ـ۱. سازنده و Propertyها

عضورفتار
__init__(self, rows: int, cols: int, elements: list)rows و cols اعداد صحیح مثبت؛ طول elements دقیقاً rows * cols؛ عناصر فقط Integer یا Complex
rows، colsProperty فقط‌خواندنی
elementsProperty فقط‌خواندنی که tuple برمی‌گرداند، نه فهرست داخلی قابل‌تغییر
__eq__(self, other)برابری ابعاد و اعضای متناظر
__add__، __mul__، __neg__عملگرهای ماتریسی؛ جزئیات در بخش ۳

اعضا به ترتیب سطر به سطر ذخیره می‌شوند. مثلاً ماتریس ۲×۳ با [1,2,3,4,5,6] به شکل [[1,2,3],[4,5,6]] است؛ البته عناصر واقعی باید شیء Integer باشند.

۲ـ۲. متدهای ایستا @staticmethod

امضای دقیقخروجی / شرط
Matrix.make_unit_matrix(n)ماتریس همانی n × n با اعضای Integer؛ n مثبت
Matrix.get_ith_row(matrix, i)لیست اعضای سطر با اندیس صفرمبنا؛ اندیس نامعتبر: IndexError
Matrix.get_ith_col(matrix, j)لیست اعضای ستون با اندیس صفرمبنا؛ اندیس نامعتبر: IndexError
Matrix.is_zero_matrix(matrix)بولین؛ تمام اعضا صفر باشند، شامل Complex(0,0)
Matrix.is_unit_matrix(matrix)بولین؛ فقط برای ماتریس مربعی؛ قطر اصلی یک و باقی خانه‌ها صفر
Matrix.is_top_triangular_matrix(matrix)بولین؛ فقط مربعی و همه عناصر زیر قطر اصلی صفر
Matrix.is_bottom_triangular_matrix(matrix)بولین؛ فقط مربعی و همه عناصر بالای قطر اصلی صفر

در همه این متدها، آرگومان matrix باید نمونه Matrix باشد؛ در غیر این صورت TypeError. برای بررسی ویژگی‌های همانی و مثلثی، ماتریس نامربعی False برمی‌گرداند. ماتریس صفر مربعی هم بالامثلثی و هم پایین‌مثلثی محسوب می‌شود.

۲ـ۳. متد کلاسی @classmethod

امضای دقیقرفتار
Matrix.make_matrix_from_string(cls, elements: str)تبدیل رشته به نمونه ماتریس؛ هر سطر با ; و هر عضو با فاصله جدا می‌شود.

برای مثال رشته "1 2 3; 4 5+2i 6" یک ماتریس ۲×۳ می‌سازد. برای ساخت اعضا باید از Integer.from_string و Complex.from_string استفاده کنید؛ استفاده از eval ممنوع است. سطرهای نامساوی یا رشته خالی: ValueError.

بخش ۳

سربارگذاری عملگرها، چندریختی و Duck Typing

۳ـ۱. عملگر جمع +

  • جمع Matrix + Matrix فقط با ابعاد برابر مجاز است؛ در غیر این صورت ValueError.
  • جمع ماتریس با Integer یا Complex یعنی افزودن عدد به تک‌تک خانه‌ها.
  • جمع عدد با ماتریس در هر دو ترتیب باید یکسان کار کند: matrix + scalar و scalar + matrix.

۳ـ۲. عملگر ضرب *

  • ضرب دو ماتریس با ابعاد (r × k) و (k × c) تعریف می‌شود؛ در غیر این صورت ValueError.
  • ضرب ماتریس در عدد، تک‌تک خانه‌ها را ضرب می‌کند. هر دو ترتیب matrix * scalar و scalar * matrix باید پشتیبانی شوند.
  • در ضرب ماتریسی از get_ith_row و get_ith_col استفاده کنید.
  • ترتیب ضرب دو ماتریس را جابه‌جا نکنید؛ ضرب ماتریسی لزوماً جابه‌جایی‌پذیر نیست.

۳ـ۳. قرینه و تفریق

در هر زیرکلاس، __neg__ را تکمیل کنید. متد __sub__ باید از کلاس پایه به ارث برسد. بنابراین matrix1 - matrix2، matrix - scalar، scalar - matrix و تفریق انواع عددی باید کار کنند.

۳ـ۴. خطاهای عملگرها

برای عملوندی غیر از Integer، Complex یا Matrix (مثلاً "3" یا 3.0) در +، * و -، TypeError ایجاد کنید. عملگرها نباید اشیای اولیه را تغییر دهند.

۳ـ۵. تابع مستقل multiply(a, b)

این تابع خارج از کلاس‌ها قرار می‌گیرد و فقط عبارت a * b را محاسبه و برمی‌گرداند؛ نباید با isinstance نوع ورودی را محدود کند. به این ترتیب با هر شیئی که عملگر ضرب معتبر دارد نیز کار می‌کند.

خروجی مورد انتظار بخش ۳: اجرای همه ترکیب‌های عملگرها، ارث‌بری متد تفریق، تابع multiply و تست خطاها و چندریختی.

نمونه‌های قابل اجرا برای درک قرارداد

این مثال‌ها بخشی از قرارداد هستند و باید بدون نیاز به تغییر اجرا شوند:

from algebra import AlgebraicElement, Integer, Complex, Matrix, multiply

x = Integer(3)
y = Complex(2, 1)
assert isinstance(x, AlgebraicElement)
assert isinstance(y, AlgebraicElement)
assert (x + y) == Complex(5, 1)
assert (x * y) == Complex(6, 3)
assert (Integer(8) - Integer(5)) == Integer(3)
assert Integer.from_string("-12") == Integer(-12)
assert Complex.from_string("5+2i") == Complex(5, 2)

m = Matrix.make_matrix_from_string("1 2; 3 4")
n = Matrix.make_matrix_from_string("2 0; 1 2")
assert Matrix.get_ith_row(m, 1) == [Integer(3), Integer(4)]
assert Matrix.get_ith_col(m, 0) == [Integer(1), Integer(3)]
assert (m * n) == Matrix.make_matrix_from_string("4 4; 10 8")
assert (Integer(2) + m) == (m + Integer(2))
assert multiply(m, Integer(2)) == m * Integer(2)
assert Matrix.is_unit_matrix(Matrix.make_unit_matrix(3))
assert not Matrix.is_unit_matrix(m)
