تمرین کشف خطا با Unit Testing

مطالعهٔ موردی: کلاس رانندهٔ اسنپ‌باکس Driver

۱. صورت مسئله

کلاسی به نام Driver برای مدیریت رانندگان اسنپ‌باکس طراحی شده است. هر راننده دارای نام کاربری، موقعیت، اعتبار و وضعیت است. وضعیت اولیه FREE و اعتبار اولیه صفر است. هزینه سفارش از نوع Decimal است.

بخشرفتار مورد انتظار
Driver(username, position)نام کاربری باید رشتهٔ غیرخالی و فقط شامل حروف و ارقام باشد. موقعیت باید tuple شامل دقیقاً دو عدد صحیح باشد. برای نوع نامعتبر TypeError و برای مقدار نامعتبر ValueError ایجاد شود.
assign_order(cost, destination)هزینه باید Decimal مثبت و مقصد یک موقعیت معتبر باشد. اگر راننده مشغول است RuntimeError ایجاد شود؛ در غیر این صورت وضعیت BUSY و خروجی True باشد.
deliver()اگر سفارش فعال نیست RuntimeError ایجاد شود. در تحویل موفق، موقعیت به مقصد و وضعیت به FREE تغییر کند؛ ۸۰٪ هزینه به اعتبار راننده و ۲۰٪ به Driver.company_credit افزوده شود. زمان با datetime.now() ثبت و چهارتایی (username, position, credit, delivery_time) بازگردانده شود.

دو ویژگی کلاسی Driver.total_drivers و Driver.company_credit نیز باید از طریق خود کلاس قابل دسترسی باشند. کلاس فقط سه متد اصلیِ سازنده، اختصاص سفارش و تحویل را دارد.

مأموریت شما

کد ارائه‌شده دقیقاً دو خطای منطقی عمدی دارد. بدون تغییر دادن کلاس، تست‌هایی با کتابخانه unittest بنویسید که رفتار نادرست را آشکار کنند. معیار درستی، صورت مسئله است، نه خروجی فعلی برنامه.

۲. چه چیزی باید تحویل دهید؟

  1. حداقل دو تست مستقل برای کشف دو خطا.
  2. برای هر تست: رفتار مورد آزمایش، نتیجهٔ مورد انتظار و نتیجهٔ واقعی را توضیح دهید.
  3. خروجی اجرای تست‌ها را ثبت کنید.
  4. کد اصلی کلاس را تا پایان مرحلهٔ کشف خطا تغییر ندهید.
یادآوری: تستی که صرفاً اجرا می‌شود اما هیچ assert ندارد، صحت رفتار برنامه را بررسی نمی‌کند. FAIL در این تمرین، اگر ناشی از کشف رفتار غلط باشد، نشانهٔ موفقیت تست شماست.

۳. پیاده‌سازی کلاس Driver

from datetime import datetime
from decimal import Decimal

class Driver:
    total_drivers = 0
    company_credit = Decimal('0')

    def __init__(self, username, position):
        if not isinstance(username, str):
            raise TypeError('Invalid username type')
        if not username or not username.isalnum():
            raise ValueError('Invalid username')
        if not isinstance(position, tuple):
            raise TypeError('Invalid position type')
        if len(position) != 2:
            raise ValueError('Invalid position')
        if not all(type(x) is int for x in position):
            raise TypeError('Invalid coordinates')

        self.username = username
        self.position = position
        self.credit = Decimal('0')
        self.status = 'FREE'
        self.cost = None
        self.destination = None
        Driver.total_drivers += 1

    def assign_order(self, cost, destination):
        if self.status == 'BUSY':
            raise RuntimeError('Driver is busy')
        if not isinstance(cost, Decimal):
            raise TypeError('Invalid cost type')
        if cost <= Decimal('0'):
            raise ValueError('Cost must be positive')
        if not isinstance(destination, tuple):
            raise TypeError('Invalid destination type')
        if len(destination) != 2:
            raise ValueError('Invalid destination')
        if not all(type(x) is int for x in destination):
            raise TypeError('Invalid coordinates')

        self.cost = cost
        self.destination = destination
        self.status = 'BUSY'
        return True

    def deliver(self):
        if self.status != 'BUSY':
            raise RuntimeError('No active order')

        self.position = (self.destination[1], self.destination[0])
        self.status = 'FREE'
        self.credit += self.cost * Decimal('0.8')
        Driver.company_credit += self.cost * Decimal('0.1')
        delivery_time = datetime.now()

        return (self.username, self.position,
                self.credit, delivery_time)

self.assertEqual(actual, expected) — self.assertTrue(condition) — self.assertFalse(condition) — with self.assertRaises(ValueError):
